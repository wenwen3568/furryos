# FurryOS 品牌令牌（唯一权威来源）

所有四层视觉资产必须引用本文件的色值与爪印符号，禁止成员自行另创配色。
如需调整，必须经队长批准后统一替换。

## 1. 调色板（蓝白配色）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `furryos-blue` | `#1A6FD4` | 主强调色：按钮、选中态、爪印、强调文字 |
| `furryos-blue-dark` | `#0F4C8C` | 深蓝：正文文字、深色背景 |
| `furryos-blue-deep` | `#0A3568` | 最深蓝：标题、启动画面深色端 |
| `furryos-blue-light` | `#D6E6F7` | 浅蓝：分区背景、边框、卡片底 |
| `furryos-blue-pale` | `#EAF2FF` | 极浅蓝：页面/窗口背景 |
| `furryos-white` | `#FFFFFF` | 白色：输入区、主背景、文字反色 |
| `furryos-text` | `#12283F` | 主文字色（深蓝，确保在浅底上可读） |
| `furryos-text-muted` | `#4A637C` | 次要文字色 |
| `furryos-accent-hover` | `#2C85EC` | 悬停态（比主强调色亮一档） |

对比度校验（WCAG）：
- `#12283F` on `#EAF2FF` ≈ 12.9:1（正文，AAA）
- `#12283F` on `#FFFFFF` ≈ 15.2:1（正文，AAA）
- `#FFFFFF` on `#1A6FD4` ≈ 4.7:1（按钮文字，AA 大字/UI 组件）
- `#FFFFFF` on `#0F4C8C` ≈ 7.4:1（按钮文字，AAA）

## 1.1 语义色（非品牌色，但同样集中管理）

品牌调色板之外，界面还需要「错误/失败」这类语义色。它们不是品牌色，但同样
不允许在各组件里各写一份：SDDM 主题统一从 `components/Theme.qml` 取。

| 令牌 | 色值 | 用途 | 说明 |
|---|---|---|---|
| `furryos-negative` | `#B3261E` | 登录失败提示文字 | 在 `furryos-blue-pale` 上对比度 5.80:1（AA 达标）；KDE 的 `#DA4453` 只有 3.78:1，故不采用 |

`FurryOS.colors` 里 KDE 的 `ForegroundNegative` 仍是上游 Breeze 的 `#DA4453`
（那是由 KDE 语义主题消费的键，属于另一条渲染路径）；两者用途不同，不要互相替换。

## 2. 爪印符号

唯一权威符号：`assets/brand/paw.svg`（256x256 viewBox），光栅版 `assets/brand/paw.png`。
爪印采用「爪印符号」而非写实兽爪：圆润主垫 + 四颗椭圆脚趾，纯色单色填充，
以便在不同底色上通过 `currentColor`/重新着色复用。

- 装饰性使用：浅色底上可用 `furryos-blue-light` 或低透明度 `furryos-blue`。
- 禁止遮挡输入区域：登录界面爪印仅出现在输入框之外的背景区域。
- 禁止使用上游（Ubuntu）任何品牌素材、Logo 或商标元素。

## 3. 命名合规底线

- 面向用户的系统名称一律为 `FurryOS`（发行版名、ISO 卷标、启动菜单、欢迎信息、图形系统信息）。
- 允许使用「基于 Ubuntu」表述说明上游来源。
- 包管理兼容所需的底层标识（如 `ID=ubuntu` 的 os-release、`lsb_release` 依赖链）可保留，但
  必须确保所有用户可见名称与横幅不含 Ubuntu 字样。
- 禁止在 ISO 卷标、启动画面、壁纸、登录界面出现 Ubuntu 商标或 Logo。

## 4. 动效参数（交互动效层统一）

| 参数 | 值 | 理由 |
|---|---|---|
| 点击反馈时长 | 200–300ms | 轻快、有回应，无夸张弹跳 |
| 登录按钮悬停 | 120–160ms 颜色/缩放 | 即时回应 |
| 登录按钮按下 | 180–240ms 缩放 0.96 + 颜色加深 | 按下确认感 |
| 密码错误抖动 | 320ms，±6px，2 次 | 轻微提示，不干扰 |
